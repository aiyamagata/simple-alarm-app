# Simple Alarm App

シンプルなアラームアプリです。ブラウザで動作します。

## 機能

- **時刻指定モード**: 指定した時刻にアラーム
- **カウントダウンモード**: 指定した時間後にアラーム
- **ビジュアル通知**: 画面が赤くフラッシュしてアラームを通知

## 使い方

1. ブラウザで `alarm.html` を開く
2. 「時刻指定」または「カウント」タブでモードを選択
3. アラーム時刻（または時間）を入力
4. 「設定」ボタンをクリック
5. 時刻に達したら画面が赤くフラッシュします

## 必要なもの

- ブラウザ（Chrome、Firefox、Safari など）
- インターネット接続不要

## ブラウザ対応

- Chrome
- Firefox
- Safari
- Edge
